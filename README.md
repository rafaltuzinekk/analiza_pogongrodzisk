Repozytorium zawiera bezpośrednie rozwiązania obu zadań rekrutacyjnych, zrealizowane na podstawie dostarczonego pliku ze zdarzeniami StatsBomb.

**Dokumentacja rozwiązań:**
* **[Zadanie 1] `analiza_xg.ipynb`** – Skrypt w języku Python. Kod oczyszcza surową bazę z powielonych klatek i dynamicznie wylicza bilans xG z podziałem na Game State (Wygrana, Remis, Przegrana) w momencie oddawania każdego strzału.
* **[Zadanie 2] `Profil_wahadlowego.md`** – Raport taktyczny. Analiza definiująca kluczowe wskaźniki dla wahadłowego w systemach z trójką stoperów (1-3-5-2) oraz precyzująca martwe punkty formatu *event data* w ocenie zachowań przestrzennych.

Obliczenia w notatniku oparto na bibliotece zdefiniowanej w pliku `requirements.txt`.
